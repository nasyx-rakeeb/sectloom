# Token Contract

## Overview

The `packages/tokens` package defines the standard semantic variables used across all Sectloom components. It uses Tailwind CSS v4's native CSS variable support and `@theme inline` mapping.

## Structure

- **Colors**: Standard `background`/`foreground` semantic pairings for `card`, `popover`, `primary`, `secondary`, `muted`, `accent`, and `destructive`. Plus `border`, `input`, and `ring`.
- **Radii**: `--radius` base with `sm`, `md`, `lg`, and `xl` variations.
- **Containers**: `--container-sm` to `2xl` for standardizing max-width layouts.
- **Section Spacing**: `--section-sm` to `xl` for vertical padding between sections.
- **Shadows**: Standardized `card` and `popover` shadows.
- **Typography**: Roles for `heading`, `body`, and `muted` text sizing.

## Usage in Components

Components **must** use the utility classes generated by this token file.

- Use `bg-primary`, not `bg-blue-500` or `bg-black`.
- Do **not** use `dark:` variants for colors (e.g., `dark:bg-white`). The `.dark` class overrides the CSS variables natively, so `bg-primary` automatically becomes the correct color in both modes.
