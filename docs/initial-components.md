# Initial Components Selection

This document records the four component references selected for manual crafting in Phase 03.

## 1. Hero Section

- **Source ID:** 1
- **Title:** 1inch Efficiency Hero Design
- **Local Path:** `data/images/hero/001_1inch_efficiency_hero_design.jpg`
- **Selection Rationale:** This hero provides a clean, modern, centered layout with strong typography, an overline, two primary call-to-actions, and a grid of statistics below. It is highly representative of modern SaaS landing pages.

## 2. Call to Action (CTA) Section

- **Source ID:** 1
- **Title:** 1inch Apis CTA Design
- **Local Path:** `data/images/cta/001_1inch_apis_cta_design.jpg`
- **Selection Rationale:** A bold, solid-color background with a simple two-column layout. It features a strong headline on the left with a contrasting button, and a visual element on the right. We will replace the complex dotted illustration with a clean, semantic placeholder graphic or icon arrangement.

## 3. Contact Section

- **Source ID:** 2
- **Title:** After Now Contact Grid Design
- **Local Path:** `data/images/contact/002_after_now_contact_grid_design.jpg`
- **Selection Rationale:** Offers an elegant, card-based grid layout. Instead of a traditional monolithic form, it provides distinct, clickable entry points (cards) for different types of inquiries, along with an address block and social links. This is a very modern and accessible approach.

## 4. Footer Section

- **Source ID:** 2
- **Title:** 1inch Products Footer Design
- **Local Path:** `data/images/footer/002_1inch_products_footer_design.jpg`
- **Selection Rationale:** A comprehensive, multi-column footer layout. It includes a prominent brand area with a description, a primary CTA button, a dense grid of social icons, and multiple columns of navigation links (Products, Chains). It serves as an excellent stress test for responsive stacking.
